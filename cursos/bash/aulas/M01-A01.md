# M01-A01 — Terminal, shell e Bash

## Objetivo e pré-requisitos

Distinguir terminal, shell, Bash e programa executado, identificando o interpretador usado. Primeira aula; não exige aulas anteriores.

## Evidência e critérios essenciais

Evidência: explicação própria dos quatro conceitos e diagnóstico do ambiente local.

- C01: distingue as quatro funções e explica o percurso de uma instrução até sua execução.
- C02: identifica Bash e sua versão com evidência local, sem deduzir o shell atual apenas de SHELL.

## Contextualização e fundamentação

O terminal é a interface de texto pela qual você interage com programas. O shell interpreta a linha de comando e coordena sua execução. Bash é uma implementação de shell e também uma linguagem de programação. Um programa externo, como Python, executa seu próprio trabalho depois de ser iniciado pelo shell.

Usar um terminal Linux não comprova que o shell ativo é Bash. A identificação será feita no ambiente de Bruno; a versão do ambiente de Orion não vale como evidência do aluno.

## Demonstração didática

Em um shell Bash interativo, ao digitar `ls`, o terminal transmite a entrada; Bash interpreta a instrução e resolve o comando; a ferramenta executa a listagem; sua saída aparece no terminal. O detalhamento de resolução de comandos será trabalhado em M01-A04.

## Fundamentação desenvolvida após a sondagem

A explicação inicial foi breve demais para exigir do aluno uma defesa técnica. As primeiras respostas servem como sondagem prévia; não comprovam dificuldade após ensino. Saber usar um comando e ter vocabulário para descrevê-lo são capacidades distintas.

O terminal é a interface em que Bruno digita e vê os resultados. Bash é o shell ativo identificado nessa sessão: interpreta a linha de comando e coordena a execução. Python é outro programa, responsável por executar o código Python.

Em `python arquivo.py`, a palavra `python` identifica o comando a iniciar e `arquivo.py` é um argumento: o nome ou caminho do arquivo fornecido ao programa. Ao pressionar Enter, a linha chega ao shell; Bash interpreta a instrução e inicia o interpretador com esse argumento. Python abre o arquivo e executa o código nele contido. Quando o programa produz texto na saída conectada ao terminal, esse texto aparece na interface.

Neste nível introdutório, chamaremos o programa Python de interpretador. Bash interpreta a linha de comando; Python processa o código do arquivo. O terminal fornece a interface de interação.

A expressão "encaminhar o arquivo" pode representar uma aproximação inicial, mas o mecanismo ensinado é passar o nome/caminho como argumento ao programa iniciado.

Não repetir a solicitação de reformulação imediatamente. Permitir dúvidas e aprofundar a fundamentação antes de retomar a verificação.

## Aplicação inicial

Considerando que o shell seja Bash: quando você digita `python arquivo.py` no terminal, qual é o papel do terminal, do Bash e do Python? Explique com suas palavras.
