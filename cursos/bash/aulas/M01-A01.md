## Terminal, shell e Bash

Linux é o sistema operacional usado por Bruno. O terminal é a interface de texto em que ele digita e vê resultados. O shell é o programa que interpreta a linha de comando e coordena a execução. Bash é uma implementação de shell e também uma linguagem de programação.

Usar Linux ou abrir um terminal não comprova que o shell ativo é Bash. Outros shells podem ser usados no mesmo sistema. Um programa externo, como Python, realiza seu próprio trabalho depois de ser iniciado pelo shell.

## Demonstração: iniciar Python com um arquivo

No comando `python arquivo.py`, a palavra `python` identifica o comando a iniciar e `arquivo.py` é um argumento: o nome ou caminho do arquivo fornecido ao programa.

Ao pressionar Enter:

1. A linha digitada chega ao shell.
2. Bash interpreta a instrução e inicia Python, passando o caminho como argumento.
3. Python abre o arquivo e executa o código nele contido.
4. Se o programa produzir texto na saída conectada ao terminal, esse texto aparece na interface.

Bash interpreta a linha de comando; Python processa o código Python. O terminal fornece a interface de interação. Neste exemplo introdutório, usamos o termo interpretador Python; detalhes de compilação e execução interna não são necessários para este objetivo.

## Argumento, opção e flag

No comando `python --version`, Bash inicia Python com o argumento `--version`. Python reconhece a opção e escreve a versão do executável iniciado. O terminal exibe a saída; Bash não produz por conta própria a informação da versão do Python.

Um argumento é uma informação passada ao comando. Uma opção é um argumento que seleciona um comportamento, geralmente começando com `-` ou `--`. Flag é um nome frequentemente usado para uma opção sem valor adicional. Assim, `--version` é argumento, opção e pode ser chamada de flag. Em `python arquivo.py`, o caminho do arquivo é um argumento posicional.

O tratamento completo de argumentos e opções pertence a aulas posteriores; aqui eles servem para explicar a divisão de responsabilidades.

## Diagnóstico do ambiente

Em uma sessão interativa de terminal no Linux:

```bash
ps -p "$$" -o comm=
bash --version
```

`$$` representa o identificador do processo do shell. `ps -p` seleciona esse processo; `-o comm=` mostra seu nome sem cabeçalho. O segundo comando informa a versão instalada do Bash. Ter Bash instalado não comprova, sozinho, que ele é o shell ativo.
