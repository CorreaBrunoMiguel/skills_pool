# Cursos e cadeiras

Cada matéria tem uma pasta `cursos/<curso-id>/`, com materiais, referências e entregas. Ainda não há cursos cadastrados.

| Local de um curso | Conteúdo | Autoria |
| --- | --- | --- |
| `README.md` | Apresentação e links para a administração | Orion |
| `aulas/` | Materiais identificados por aula | Orion |
| `referencias.md` | Documentação e leituras utilizadas | Orion |
| `atividades/` | Trabalho do aluno, organizado por aula ou atividade | Bruno |
| `projetos/` | Trabalho integrador, quando pertinente | Bruno |

Currículo, avaliações e estado ficam em `secretaria/cursos/<curso-id>/`. O aluno não precisa editar esses registros para estudar ou entregar uma atividade.
