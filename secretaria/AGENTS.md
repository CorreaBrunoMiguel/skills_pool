# Responsabilidade da secretaria

Esta pasta é mantida por Orion. Leia e siga o `AGENTS.md` da raiz.

- Mantenha normas, templates, ferramentas, catálogo e registros oficiais.
- Escolha Markdown para instruções e materiais textuais; JSON para dados estruturados; Python para ferramentas administrativas.
- O currículo vigente é pré-determinado. Para revisá-lo, incremente a versão, registre motivo e preserve avaliações ancoradas na versão anterior.
- O estado registra aprendizagem demonstrada, não apenas conteúdo exposto.
- Não confunda templates, cursos em planejamento e cursos em andamento.
- Não solicite ao aluno manutenção rotineira dos arquivos administrativos.
- Execute a validação antes de publicar. Ela verifica estrutura e coerência, não a qualidade pedagógica ou a autenticidade de uma evidência.
