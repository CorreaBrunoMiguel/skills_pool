# Administração dos cursos

Cada curso cadastrado terá uma pasta `<curso-id>/` com `curso.json`, `curriculo.json`, `estado.json` e `registro.json`.

Responsabilidade editorial: Orion. O catálogo inicial está vazio. Os exemplos em `../templates/administracao/` são modelos, sem matrícula, aula iniciada ou aprovação real.
